Diccionario Maestro de HTML

Introducción al lenguaje

El HTML (HyperText Markup Language) es el cimiento de casi todo lo que ves en internet.
Si comparamos una página web con un edificio, el HTML sería la estructura de vigas y
paredes; sin él, no habría nada donde colgar el diseño o la interactividad.

Etiquetas de Formato

hr y br nos ayudan a separar textos o párrafos, logrando mantener una estructura mas ordenada visualmente.
hr: crea una linea de división
br: crea un salto de línea
